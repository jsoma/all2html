# Docs Screenshot Checklist

Twelve `> Screenshot placeholder` blocks were shipping live on the public site
across eight pages — the built site rendered them as blockquotes telling readers
to crop a screenshot. They are removed from `docs/` and tracked here instead.

Add each image only when it exists. Do not re-add a placeholder to `docs/`: an
unfinished note in a published page is worse than a missing image.

Suggested location: `docs/assets/screenshots/`, referenced with normal Markdown
image syntax and real alt text.
